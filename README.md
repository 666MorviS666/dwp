# dwp — вероятность победы в Dota 2

Две модели: оценка по драфту до старта и оценка по состоянию на поле
поминутно, плюс разложение каждой оценки на вклады и детектор переломных
моментов. Веб-панель для лайва, режим для OBS, слепой тест против самого
себя.

Целевое применение — аналитика и оверлей для трансляции.
**Не для ставок.** Почему — отдельный раздел в `dwp/README.md`: там
перечислены конкретные механизмы, из-за которых калиброванная модель всё
равно проигрывает рынку.

---

## Запуск

```bash
pip install -r dwp/requirements.txt
export STEAM_API_KEY=...        # Windows: set STEAM_API_KEY=...
python -m dwp.web               # http://127.0.0.1:8765/
```

Или в контейнере — `cp .env.example .env`, вписать ключ, затем
`docker compose up -d --build`.

Без ключа и без сети тоже есть что посмотреть:

```bash
python -m dwp.synthetic     # ~3 с: 4000 матчей с известной истинной силой
python -m dwp.train         # ~10 с: обе модели, калибровка, метрики
python -m dwp.web --from-file data/live_dump_late.json
```

## Устройство

```
dwp/          пакет: сбор, признаки, обучение, лайв, веб-панель, проверки
models/       обученные модели (ансамбль по пяти сидам + одиночные)
data/         справочники, производные таблицы, лайв-логи, слепой тест
```

Сырая выгрузка матчей (`data/matches/`, 3.3 ГБ) в репозиторий не едет —
пересобирается через `python -m dwp.collect`. Что ещё не едет и чем это
вернуть — таблица в [`DEPLOY.md`](DEPLOY.md).

## Проверки

```bash
python -m dwp.check_schema         # ОБЯЗАТЕЛЬНО до обучения на реальных данных
python -m dwp.test_web_snapshot    # весь веб-путь на настоящем матче
python -m dwp.test_live_replay --n 40
python -m dwp.test_builds
python -m dwp.test_killfeed
python -m dwp.test_forecast
```

`test_web_snapshot` — сквозной: берёт завершённый матч, поминутно собирает
из него ответы в схеме `GetRealtimeStats` и гонит через тот же
`Poller.snapshot`, что работает в браузере. Проверяет заодно, что число на
панели совпадает с числом консольного пути до 1e-9.
